# COOANC 경제 교육 커리큘럼

COOANC는 아이들의 경제 지능(EQ) 성장을 위한 6단계 레벨 시스템을 제공하며, 각 레벨은 아이들의 발달 단계에 맞춰 점진적으로 경제 개념을 확장하고 앱 UI 기능을 해제합니다.

## 1. 6단계 레벨 시스템

| 레벨 | 명칭 | 핵심 학습 내용 | UI 해제 규칙 |
|---|---|---|---|
| Lv.0 | 씨앗 | 노동과 보상의 연결 | 돈바구니만 표시, 저금통/지갑 완전 숨김 |
| Lv.1 | 보상 이해 | 미션 수행을 통한 보상 획득 및 저금통 사용 | 저금통 해제 (돈바구니 중앙 크게, 저금통 우측 작게) |
| Lv.2 | 경제 가치 | 화폐의 가치 이해 및 지갑 사용 | 지갑 해제 (돈바구니 중앙, 저금통 우측, 지갑 좌측) |
| Lv.3 | 저축 | 저축의 중요성 및 목표 설정 | 저축 목표 기능 해제 (스킵 불가) |
| Lv.4 | 나눔·선물 | 타인과의 나눔 및 선물 경험 | 기부/선물 기능 + 나눔 뱃지 해제 |
| Lv.5 | 투자 | 자산 증식 및 투자 개념 이해 | 투자 미션 + 최종 뱃지 + 섬 지도 완성 |

## 2. 레벨 평가 원칙

COOANC의 레벨업은 아이들의 자율적인 학습과 미션 수행을 기반으로 하며, 체류 기간에 제한을 두지 않습니다. 필수 트리거 달성 시 즉시 레벨업이 가능합니다.

### 2.1. 스킵 가능/불가 레벨

*   **스킵 가능 레벨**: Lv.1 (만 7세 이상), Lv.2 (만 8세 이상), Lv.4 (만 9세 이상)
*   **스킵 불가 레벨**: Lv.0 (온보딩), Lv.3 (저축 필수 경험)

### 2.2. 스킵 조건

레벨 스킵은 다음 3단계 과정을 통해 진행됩니다.
1.  **앱 제안**: 앱 내에서 레벨 스킵을 제안합니다.
2.  **부모 승인**: 부모의 최종 승인이 필요합니다.
3.  **이해도 퀴즈**: 해당 레벨의 핵심 경제 개념에 대한 이해도 퀴즈를 통과해야 합니다.

## 3. 연령별 진입 경로

아이의 연령에 따라 적절한 레벨에서 학습을 시작할 수 있도록 진입 경로를 제공합니다.

| 연령 | 시작 레벨 | 스킵 가능 레벨 |
|---|---|---|
| 만 3~5세 | Lv.0 | 없음 |
| 만 6~7세 | Lv.0 | Lv.1 |
| 만 8~9세 | Lv.0 | Lv.1, Lv.2 |
| 만 10세+ | Lv.0 | Lv.1, Lv.2, Lv.3, Lv.4 |

## 4. 이벤트 트리거 목록

각 레벨업을 위한 주요 이벤트 트리거는 `child_trigger_fired` 테이블에 기록되며, 다음 조건들을 달성 시 레벨업이 진행됩니다.

| 레벨 | 이벤트 트리거 |
|---|---|
| Lv.0 | `FIRST_MISSION`, `FIRST_BASKET_CREDIT`, `STREAK_3`, `BASKET_100` |
| Lv.1 | `FIRST_PIGGY_TRANSFER`, `ISLAND_ARRIVE_1`, `BASKET_300` |
| Lv.2 | `FIRST_WALLET_TRANSFER`, `PIGGY_500`, `FIRST_PURCHASE_REQUEST` |
| Lv.3 | `PIGGY_1000`, `SAVINGS_GOAL_COMPLETE`, `ISLAND_ARRIVE_2` |
| Lv.4 | `FIRST_DONATION_OR_GIFT`, `DONATION_GIFT_3`, `ISLAND_ARRIVE_3` |
| Lv.5 | `TOTAL_CREDITS_5000`, `ISLAND_ARRIVE_4`, `DONATION_GIFT_10` |
